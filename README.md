# GrayMoon.Release

The official home for GrayMoon Desktop downloads, updates, and release notes.

**[Download GrayMoon Desktop 0.1.0 for Windows](https://github.com/Jandini/GrayMoon.Release/releases/download/0.1.0/GrayMoon.Desktop-stable-Setup.exe)** or install with winget:

```powershell
winget install graymoon
```

## What is GrayMoon?

[GrayMoon](https://github.com/Jandini/GrayMoon) is a multi-repository workspace for .NET teams. It clones, branches, updates, and pushes across every repository in a workspace as one coordinated action, in dependency order. It also shows Git changes, GitHub Actions, and pull requests for every repository in one place.

GrayMoon Desktop bundles the GrayMoon app and Worker into a single Windows installer. It runs in a native window with a tray icon and notifications.

## Install

1. Download and run `GrayMoon.Desktop-stable-Setup.exe`.
2. Launch **GrayMoon** from the Start menu.
3. Add a GitHub connector and create your first workspace.

Requires Windows 10 22H2 or later. Desktop checks this repository for updates on startup and asks before installing one.
